# SUGAR Cosmetics Instagram Performance Analytics

**Author:** Srivalli Korada  
**Project Type:** Data Analytics  
**Visualization Tool:** Tableau Public

## 1. Project Overview

This project focuses on analyzing Instagram performance for SUGAR Cosmetics using a dataset of approximately 50,000 records. The project uses data visualization to explore social media engagement, content performance, campaign metrics, and key performance indicators (KPIs).

An interactive Tableau dashboard presents the analyzed metrics in a visual format, making it easier to explore patterns and compare performance across different categories.

## 2. Project Objectives

- Analyze Instagram performance metrics.
- Track key performance indicators (KPIs).
- Explore monthly performance trends.
- Compare campaign and post-type performance.
- Examine engagement patterns across weekdays.
- Analyze hashtag combinations and engagement.
- Visualize the engagement funnel using Tableau.

## 5. Dataset

The project uses an Instagram performance dataset containing approximately 50,000 records.

The dataset supports analysis of available performance metrics, campaign information, post categories, engagement, and related trends.

**Dataset file:** `Dataset/sugar_cosmetics_instagram_data - sugar_cosmetics_instagram_data.csv`

The dataset is included in this repository only for project demonstration purposes, subject to the applicable sharing permissions.

### KPI Analysis

## 8. Limitations

- The dataset does not contain captions or a unique post ID.
- Hashtag analysis focuses on combinations rather than independently identifying each unique hashtag.
- The analysis is limited to the fields and records available in the dataset.
- Results represent the available dataset and should not automatically be interpreted as a complete representation of all SUGAR Cosmetics Instagram activity.
